# Generated Template

The `api` template is intentionally small. It is meant to demonstrate project setup conventions, not to act as a full application framework.

Generated projects include:

- Root README and proprietary license
- Git ignore file
- Source, test, and documentation folders
- GitHub Actions workflow
- Minimal API project with a health endpoint and one sample endpoint

Generated code is public-safe and generic. It does not include private project names, private architecture, credentials, tenant values, or internal service URLs.
